One short line about office life: seven drafts are scored against the judge brief published with the bounty (setup and turn first, then recognition, surprise, tightness, freshness), and the winning line is written to `/output/entry.txt`. The winner turns on the phrase every office worker knows — "per my last email" — and lands on a punchline about HR, passive aggression, and quiet promotions.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. Deterministic, standard library only, no network, no clock, no randomness. The program writes exactly one file, `/output/entry.txt`, holding the winning joke (1 to 200 characters).
